Política de privacidad

Última actualización: 18 de octubre de 2026

Panel de vida es una aplicación personal que usa únicamente su propietario, Miguel Mieres, con sus propias cuentas de Google.

Datos a los que accede

  • Gmail: solo lectura, para mostrar los correos recientes.
  • Google Calendar: para mostrar y gestionar los eventos.
  • Google Tasks: para mostrar y gestionar las tareas.
  • Google Drive: para mostrar y abrir archivos.

Cómo se usan

Los datos solo se muestran en el panel, que funciona en un servidor doméstico privado. Los permisos de acceso de Google se guardan en ese servidor.

Los datos no se venden, no se comparten con terceros, no se usan con fines publicitarios y no se usan para entrenar modelos de inteligencia artificial.

Uso de los datos de Google

El uso de la información recibida de las API de Google cumple la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Cómo retirar el acceso

El acceso se puede retirar en cualquier momento desde myaccount.google.com/permissions.
